J&M CONSTRUCCIONES · JM COTIZA

Política de Privacidad

Última actualización: 30 de septiembre de 2026

1. Responsable

Esta política de privacidad corresponde a JM COTIZA, aplicación desarrollada y distribuida por J&M CONSTRUCCIONES.

Para consultas relacionadas con privacidad, los usuarios pueden utilizar el mecanismo de contacto disponible en el sitio web de J&M CONSTRUCCIONES.

2. Qué información maneja JM COTIZA

JM COTIZA permite al usuario elaborar y gestionar cotizaciones. El usuario puede introducir información comercial y de proyecto, como nombres o datos de clientes, partidas, conceptos, cantidades, unidades, precios, materiales, costos, porcentajes y totales.

La aplicación no requiere crear una cuenta de usuario para utilizar sus funciones principales.

3. Finalidad del uso de la información

La información introducida por el usuario se utiliza para proporcionar las funciones propias de la aplicación, incluyendo la creación, edición, cálculo y presentación de cotizaciones y presupuestos.

J&M CONSTRUCCIONES no utiliza la información introducida para publicidad personalizada ni la vende a terceros.

4. Compartición y transferencia

JM COTIZA no comparte deliberadamente con terceros la información comercial introducida por el usuario para fines publicitarios o de venta de datos. Si en una versión futura se incorpora una función que transfiera información a un servicio externo, esta política será actualizada antes de aplicar dicho tratamiento.

5. Almacenamiento y seguridad

El usuario debe evitar introducir información que no sea necesaria para sus cotizaciones. J&M CONSTRUCCIONES aplica medidas razonables para proteger la información dentro del funcionamiento de la aplicación, pero ningún sistema electrónico puede garantizar seguridad absoluta.

6. Conservación y eliminación

El usuario controla la información que introduce en JM COTIZA. Cuando la aplicación almacena información localmente en el dispositivo, el usuario puede eliminarla utilizando las funciones de gestión o eliminación disponibles en la aplicación y, cuando corresponda, mediante las opciones de almacenamiento del dispositivo.

JM COTIZA no crea una cuenta de usuario que requiera un procedimiento independiente de eliminación de cuenta.

7. Permisos y datos del dispositivo

La aplicación solo debe utilizar los permisos necesarios para proporcionar sus funciones. JM COTIZA no está diseñada para recopilar ubicación precisa, contactos, mensajes, llamadas, datos de salud ni información biométrica.

8. Menores de edad

JM COTIZA es una herramienta profesional orientada a la elaboración de cotizaciones y presupuestos. No está dirigida específicamente a niños.

9. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de JM COTIZA, sus prácticas de tratamiento de datos o los requisitos legales y de las plataformas de distribución. La fecha de actualización se mostrará al inicio de esta página.

10. Contacto

Para consultas sobre privacidad, tratamiento de datos o esta política, el usuario puede comunicarse mediante la sección Contacto del sitio web de J&M CONSTRUCCIONES.
